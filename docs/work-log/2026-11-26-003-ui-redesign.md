## Objective

Rebuild the Research Trend Navigator frontend on the approved design mockup
(`apps/research-explorer/design-mockup/`) in six phases: tokens, fonts, shell and
routing; Ask; Pulse, Trends and Topic; Groups, Map and Network; Node profile, About
and Explore; quality pass. Keep every feature, endpoint and test working, change
the answer prompt to a summary-first format (new version), re-cache the 7 demos on
`enriched-cb371912e308`, and leave v4 behaviour unchanged.

## Changes and findings

Phase notes are appended below as each phase is committed.

### Phase 1: tokens, fonts, shell and routing

- **Tokens** (`frontend/src/styles/index.css`, `tailwind.config.js`): the mockup's light and dark
  CSS variables (chart paper, graphite, rule, sunken, cooling/stable/heating with AA text inks,
  entity hues; Researcher `#557626` and Topic `#B04A5A` added as muted hues). Legacy names
  (`--ground`, `--text`, `--border`, `--accent`, pills, chart colours) are aliases, so the v4
  Explorer restyles without logic changes. `--faint` is darkened to `#5F6D80` (4.9:1 on paper)
  because the Explorer uses it for text; the mockup's `#7A8794` survives as `--decor` for strokes.
- **Fonts** (`styles/fonts.css`): self-hosted through `@fontsource` (Atkinson Hyperlegible Next 400/500/700,
  Source Serif 4 variable with optical size). Atkinson Next's zero is slashed and the font has no
  unslashed alternate (checked with fontTools: features `ccmp frac locl pnum tnum`, glyphs
  `zero`, `zero.tf` only), so digits 0-9 come from Source Sans 3 through a digits-only
  `unicode-range` face ("RTN Figures") with tabular figures.
- **Theme:** light first; a stored choice wins, otherwise the OS preference, otherwise light.
- **Shell** (`components/shell/AppShell.tsx`): one left rail (Pulse, Ask with recent conversations,
  Trends, Topics, Groups, Map, Network, Explore, About at the bottom), a top bar with the global
  search trigger (⌘K, `/`) and theme toggle, and a bottom tab bar with a More sheet at ≤768 px.
  The old double header and the "NAVIGATOR" strip are gone; `TopHeader` became
  `components/explore/ExploreToolbar.tsx` (Graph/Table, Paths, Compare, Caveats, share/export).
  The version hash is no longer printed in the chrome: the toolbar says "Release graph v4" with
  the hash on hover, and About lists every version.
- **Routing** (`lib/router.ts`): real paths (`/`, `/ask/:conversation`, `/trends`, `/topics/:id`,
  `/groups/:id`, `/map/:id`, `/network`, `/network/release`, `/explore`, `/explore/table`,
  `/node/:id`, `/about`), History API with Back/Forward, and legacy URLs (`/?tab=…`, `/?mode=…`,
  `/?view=…`) rewritten on load. The store's `workspaceTab` stays the Explorer's source of truth and
  is synchronised both ways with the path, so existing `openSubject`/`setWorkspaceTab` calls work.
- **Global search** (`components/search/NavigatorSearchModal.tsx`): subjects plus enriched-graph
  organizations, researchers and papers; each hit opens its page; Enter with no hit asks the
  question. Inside Explore the v4 `SearchCommandModal` is unchanged.
- **Explore** (`components/explore/ExplorePage.tsx`): the Explorer logic moved out of `App.tsx`
  unchanged (view query, effective slice, expansion, scope restore); the sidebar-folding
  breakpoints are measured on the Explore area (viewport minus the 232 px rail).
- **v4 analytics placement:** the v4 Analytics dashboard is now Network → "Release graph (v4)
  analysis" (`/network/release`); `/?tab=analytics` redirects there.
- **v4 test navigation only** (`tests/helpers/nav.ts`): `goto("/")` → `goto("/explore")`; the
  version badge check reads the hover title; in-page Analytics/Graph tab clicks go through the
  rail (or the tab bar's More sheet at 768 px). Explorer assertions are unchanged.
